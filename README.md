# Lumary Cam — Downloads

Official downloads for **Lumary Cam**, a local-first virtual camera for macOS.

## Download

Get the latest version from the [**Releases**](https://github.com/LumaryLabsLLC/lumarycam-releases/releases/latest) page.

The app is signed with our Apple Developer ID and notarized by Apple, so it opens without security warnings.

## What is Lumary Cam?

Lumary Cam enhances your camera in real time — background blur, low-light recovery, sharpness, color grading, and one-tap presets — and publishes the result as a virtual camera you can pick in Zoom, Meet, OBS, FaceTime, Discord, and more. Everything runs locally on your Mac. No account, no cloud, no tracking.

Plug in your **iPhone over USB-C** (with the free Lumary Cam Mobile companion) and use it as a **4K camera** — the video is processed on the phone, so your Mac stays light.

## Install

1. Download the latest `.dmg` from [Releases](https://github.com/LumaryLabsLLC/lumarycam-releases/releases/latest).
2. Open it and drag **Lumary Cam** to your Applications folder.
3. Launch it and follow the in-app prompt to install the virtual camera system extension (approve it in System Settings → General → Login Items & Extensions → Camera Extensions).
4. Select **Lumary Cam** as the camera in any video app.

## Requirements

- macOS 26 or later
- For the iPhone camera: an iPhone with USB-C and the free Lumary Cam Mobile app
